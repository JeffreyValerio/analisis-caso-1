INSTRUCCIONES DE USO RÁPIDO
================================================================================

1. Clonar repositorio:
   $ git clone https://github.com/JeffreyValerio/analisis-caso-1.git
   $ cd analisis-caso-1

2. Iniciar stack:
   $ docker compose up -d

3. Verificar funcionamiento:
   $ curl http://localhost:8080/        # HTTP
   $ curl -k https://localhost:8443/    # HTTPS
   $ curl http://localhost:8080/health  # Health check

4. Ver panel de estadísticas:
   Abrir navegador: http://localhost:8404/

5. Prueba de failover:
   $ docker pause caso1-web1    # Simular crash
   $ sleep 3                     # Esperar detección
   $ curl http://localhost:8080/ # Todos los requests van a web2
   $ docker unpause caso1-web1   # Recuperar

6. Ver documentación:
   $ cat docs/ANALISIS_TECNICO.md
   $ cat docs/LOGS_EJECUCION.md
   $ cat docs/INSTRUCCIONES_USO.md
